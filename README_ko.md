# Pep2Vec: 펩타이드-MHC 제시 예측 및 리간돔 데이터셋의 오염 물질 식별을 위한 해석 가능한 모델
## 초록

개인 맞춤형 암 백신이 발전함에 따라, MHC 클래스 I(MHCI) 및 II(MHCII)에 의한 항원 제시를 정밀하게 모델링하는 것이 중요합니다. 임상 환경에서 사용되는 모델에는 고품질의 훈련 데이터가 필수적입니다. 기존의 딥 러닝 모델은 예측 성능에 중점을 두지만, 기본 데이터에 대한 신뢰도를 보장하기 위한 해석 가능성은 거의 제공하지 않습니다. 여기서는 이러한 한계를 뛰어넘는 모듈식 트랜스포머 기반 모델인 Pep2Vec을 소개합니다. 이 모델은 MHC I 및 MHC II 리간돔 데이터 모두에 대해 훈련되었으며, 각 입력 서열을 해석 가능한 벡터로 변환합니다. 이 접근 방식은 소스 단백질 특징을 통합하고 성능 향상의 원인을 명확히 하여, 유전자 발현 및 단백질-단백질 상호작용과 상관관계가 있는 영역을 보여줍니다. 또한, Pep2Vec의 펩타이드 잠재 공간은 다양한 MHC 클래스, MHC 동종이형, 펩타이드 길이 및 하위 모티프의 펩타이드 간의 관계를 나타냅니다. 이 해상도를 통해 우리 리간돔 데이터의 5.0%를 차지하는 네 가지 주요 오염 물질 유형을 체계적으로 식별할 수 있습니다. 이러한 혁신은 Pep2Vec을 MHC 제시 예측에서 성능이 뛰어난 모델로 자리매김하게 하며, 향상된 예측 정확도뿐만 아니라 오염 물질과 유사한 펩타이드의 추천을 줄여줍니다. Pep2Vec은 암 백신 및 항체 면역원성 제거와 같은 펩타이드 MHC 모델의 보다 정밀하고 효과적인 적용 개발에 대한 중요한 요구를 해결합니다.


## 리포지토리 정보
이 리포지토리에는 pep2vec 논문의 "플래그십" 모델에 대한 바이너리와 이 모델을 훈련하고 테스트하는 데 사용된 공개 데이터셋의 잠재 공간을 탐색하기 위한 대시보드가 포함되어 있습니다. 이 잠재 공간의 임베딩은 전체 데이터셋으로 훈련된 모델에서 생성된 반면, 여기의 바이너리는 해당 데이터셋의 훈련 부분으로만 훈련되었습니다.

## 모델 추론
### 설치
pep2vec.bin 파일을 로컬 디렉토리에 복사하기만 하면 모든 리눅스 운영 체제에서 실행할 수 있습니다.
리포지토리를 체크아웃하는 경우 바이너리 파일을 얻으려면 먼저 git lfs를 설치해야 합니다.
```bash
git lfs install
git clone ...
git lfs pull
```

### 사용법
추론은 다음 명령으로 실행됩니다.
```bash
./pep2vec.bin --dataset /[리포지토리에 대한 전체 절대 경로]/test_input_mhc1.csv --output_location [출력 폴더에 대한 전체 절대 경로]/test_output.parquet --mhctype mhc1
```

입력 및 출력을 정의하려면 절대 경로가 필요합니다. 출력 파일에는 매우 많은 수의 열이 있으므로 효율성을 위해 출력은 파켓 형식으로 저장됩니다.

"mhctype"은 점수를 매기는 MHC 유형에 따라 mhc1 또는 mhc2여야 합니다.

### 입력 형식
입력 형식의 예는 input_example.csv를 참조하십시오. 입력 파일은 다음 열이 있는 csv여야 합니다.

    - n_flank
       - 펩타이드 바로 앞의 5개 아미노산 서열, 사용할 수 없는 경우 '*****' 사용
    - peptide
       - 점수를 매길 펩타이드 서열, 길이는 9-25 아미노산이어야 함
    - c_flank
         - 펩타이드 바로 뒤의 5개 아미ノ산 서열, 사용할 수 없는 경우 '*****' 사용
    - allele
        - 점수를 매길 MHC1 대립유전자, 다중 대립유전자에 대해 해당 2개 대립유전자의 점수를 매기는 경우 'A*02:01__B*07:02' 형식이어야 함
        - 자세한 내용은 예제 파일 참조
        - MHC2 점수를 매기는 경우 비워 둠
    - allotype
        - 점수를 매길 MHC2 동종이형, 단일 대립유전자 또는 다중 대립유전자 점수 매기기 형식은 예제 파일 참조
        - MHC1 점수를 매기는 경우 비워 둠
    - gene_ids
        - 소스 단백질의 앙상블 유전자 ID
        - 둘 이상의 소스 유전자에 다중 매핑되는 경우 매핑이 있는 모든 gene_id 사용
        - 사용할 수 없는 경우 비워 둠, 그러나 이 제공된 모델은 gene_id가 없는 펩타이드에 대해 정의되지 않은 성능을 가짐

### 출력 형식
    - 모든 입력 열은 출력 파일에 유지됨
    - EL_pred
        - 제시 가능성의 예측 로짓 점수
    - peptide_core
        - 펩타이드의 예측된 결합 코어
    - latent_[0:1023]
        - 펩타이드의 1024차원 잠재 공간 표현
    - attn_[0:50]
        - 펩타이드의 51개 어텐션 가중치
    - 내부 처리에 사용되는 추가 열은 무시할 수 있음.
